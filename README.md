# BIG OPERAÇÃO

A arquitetura atual do painel é **Vercel + Neon/PostgreSQL**. O serviço público da Farm permanece na Cloudflare e lê somente as versões publicadas no PostgreSQL.

- [Configuração, publicação, Farm e recuperação](docs/vercel-neon.md)
- [Documentação original Cloudflare Workers + D1](docs/cloudflare-d1-legado.md) — arquitetura anterior; seus comandos não publicam o painel na Vercel.

A interface em português, ícones, contas individuais, regras de jornada, remuneração, perfis, BMs, proxies, tarefas e vendas foram preservados. Não há transferência bancária ou fechamento oficial de folha.
